# art-budgets-profiling

*Reference, for users of the technical-artist plugin looking up the `art-budgets-profiling` skill.*

| Field | Value |
|---|---|
| Name | `art-budgets-profiling` |
| Source | [`skills/art-budgets-profiling/SKILL.md`](../../skills/art-budgets-profiling/SKILL.md) |
| Use when | Setting, revising or checking art budgets, or profiling what art costs in a running build. |
| Produces | A budget table per tier and asset class; profiling reports ranking offenders by cost x count. |
| Docs owed | Budgets: reference + explanation. Repeated profiling procedure: how-to. |

## Method steps

1. Get the frame (tiers, resolution, frame target, content share)
2. Measure a reference scene
3. Split per scene, then per class
4. Write them down (template)
5. Prove with a stress scene
6. Revisit at milestones

## Supporting files

- `budget-template.md`: frame/platform table, per-class table, rules, change log
