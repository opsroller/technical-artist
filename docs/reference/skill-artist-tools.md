# artist-tools

*Reference, for users of the technical-artist plugin looking up the `artist-tools` skill.*

| Field | Value |
|---|---|
| Name | `artist-tools` |
| Source | [`skills/artist-tools/SKILL.md`](../../skills/artist-tools/SKILL.md) |
| Use when | Building or improving a tool, script, exporter, editor extension or automation for artists. |
| Produces | A small tested tool with a how-to, a reference page, a named owner, and measured improvement. |
| Docs owed | Every tool: how-to + reference; explanation for a real trade-off; tutorial if onboarding changes. |

## Method steps

1. Find the pain by watching
2. One-page brief
3. Smallest useful version
4. Design for the artist
5. Actionable errors
6. Engineer it properly (review, tests, headless)
7. Trial with real users
8. Ship with docs and support
9. Maintain or retire
